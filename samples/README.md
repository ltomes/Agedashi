# Sample Diagrams

This directory contains sample infrastructure diagrams generated by Agedashi from test data.

The GitHub Actions workflow should automatically generate these files:
- `sample-infrastructure.png` - PNG format diagram
- `sample-infrastructure.svg` - SVG format diagram
- `sample-infrastructure.pdf` - PDF format diagram

These diagrams are generated from `test/sample-graph.dot` and showcase Agedashi's ability to visualize Terraform infrastructure with AWS Architecture Icons.

If the diagrams are not present, the GitHub Actions workflow may still be running or may have encountered an error. Check the Actions tab on GitHub for workflow status.
